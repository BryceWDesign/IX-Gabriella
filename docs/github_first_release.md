# GitHub First Release Notes

This repository is prepared as the first public GitHub-ready IX-Gabriella release.

Development history included separate internal ZIP handoffs for the assistant GUI, the brain layer, and the LLM-control layer. Those internal ZIPs should be treated as build lineage, not public release numbering.

Recommended first public tag:

```text
v0.1.0
```

Recommended release title:

```text
IX-Gabriella v0.1.0: Brain-Integrated LLM-Ready Local Voice/Chat Assistant
```

Recommended release summary:

```text
Initial public source-available release of IX-Gabriella, a governed local virtual assistant prototype with browser GUI, typed chat, browser microphone dictation, spoken replies, IX-Gabriella-Brain cognitive routing, policy-bound LLM-control architecture, approval gates, correction flow, local action staging, approved-memory controls, and tamper-evident receipts.
```

Boundary note:

```text
This repo includes LLM adapters and a deterministic local language provider. It does not include trained large model weights or claim demonstrated AGI.
```
