# Intelligence Scorecard

This file defines the rating language used for IX-Gabriella. It is intentionally conservative.

```text
5/10: governed local assistant with brain layer, fast intents, approvals, receipts, and deterministic language fallback.
6/10: same system with stronger local orchestration, structured validation, correction learning, memory retrieval, and fallback provider modes.
7/10: capable hosted or local model connected, but limited tool integrations.
8/10: strong model connected, structured output stable, corrections tracked, approved memory retrieved, GUI integrated, and evals green.
8.5/10 plus: strong model plus real tools, accounts, search, calendar/email connectors, tuned voice UX, and production-grade privacy controls.
10/10: not claimed.
```

IX-Gabriella v0.1.0 intelligence-stack is built to support the 8/10 path, but it does not become 8/10 by itself unless a capable model is connected and passes the eval suite.
