# Claim Boundaries

IX-Gabriella-Brain is an advanced governed cognitive layer for a virtual assistant.

Allowed claims:

- governed cognitive assistant brain layer
- AGI-candidate architecture research direction
- receipt-backed cognitive decision packets
- simple-task downshift and complex-task planning
- memory quarantine with user approval
- human-authority-gated consequential action

Blocked claims:

- true AGI demonstrated
- consciousness demonstrated
- autonomous authority granted
- production safety certification
- assistant can act without user approval
- model output equals truth
- memory equals truth
- simulation equals execution

The repo is designed to push capability while preserving claim discipline.
