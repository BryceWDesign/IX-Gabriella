# First public release scope

This repository is prepared as the first GitHub-ready IX-Gabriella public codebase. Earlier ZIPs were internal handoff builds.

This build includes the integrated brain and a policy-bound LLM layer, but it does not include trained model weights. The correct public wording is:

```text
IX-Gabriella includes an LLM-ready governed language layer and default deterministic local provider. Strong external or local models can be connected through the provider boundary.
```

Do not claim that the repository contains a fully trained proprietary Gabriella LLM unless model weights are later trained, licensed, packaged, and documented.
