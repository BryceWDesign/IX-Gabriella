# IX-Gabriella v0.2.0 Upgrade Audit

## Upgrade mission

Turn IX-Gabriella from a governed assistant core into a local assistant surface that a user can actually interact with through a GUI and voice-capable browser.

## Added capabilities

- Local browser GUI served by the Python standard library.
- Browser microphone dictation using the browser speech-recognition surface when available.
- Browser spoken replies using speech synthesis.
- Stateful session layer for pending approvals and corrections.
- Local action store for timers, reminders, notes, list items, drafts, search requests, and smart-home staged commands.
- Confirmation buttons for approval-gated actions.
- Correction field for pending action repair.
- Receipt export endpoint.
- Health, state, chat, confirm, correct, and receipt APIs.
- Optional OpenAI-compatible HTTP chat provider adapter, configured only through environment variables.
- Windows helper script for launching the GUI.
- Expanded tests from 22 to 28 passing tests.

## Quality gate results expected

```text
pytest: 28 passed
compileall: passed
manifest: generated
```

## Non-goals for this release

- No iOS App Store binary.
- No always-on background wake phrase.
- No live smart-home connector.
- No autonomous email sending.
- No hidden memory capture.
- No ad SDK bundled.

## Why this is a real upgrade

The user can now launch a local UI, speak to Gabriella through a supported browser, receive spoken responses, review what was heard, approve or reject risky actions, correct misunderstood actions, and export receipts. The core remains governed rather than silently autonomous.
