## Integrated capability

The repository integrates the local IX-Gabriella assistant shell with IX-Gabriella-Brain and `ix_gabriella_llm`. User input flows through the brain first. Simple tasks downshift into the fast lane. Complex, clarifying, or approval-sensitive requests may consult the LLM layer for response drafting and plan critique. The LLM layer never receives direct authority to execute external side effects.

## Verified release gates

The release gate is generated by `scripts/run_quality_gate.py` and writes `QUALITY_GATE.json` plus `RELEASE_MANIFEST.sha256.json`.

Expected gate checks:

- Python source compile check.
- Full pytest suite.
- LLM behavior eval script.
- Release manifest generation.
- Forbidden marker scan.
- Cache-free ZIP packaging.

## Claim boundary

This is a serious assistant cognition and LLM-control foundation, not a demonstrated AGI claim. It is also not a production App Store app, not an always-on wake-word daemon, not a production smart-home assistant, and not a repository containing trained large model weights.
